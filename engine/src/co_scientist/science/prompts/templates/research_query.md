The query goes to a keyword index that requires EVERY term to appear in a paper. Each extra word shrinks the result set, and a query that reads like a sentence returns nothing at all.

Instructions:
1. 3-6 key terms separated by spaces. Never a sentence, never a question.
2. Use the established terminology a paper on this topic would actually use, including standard gene/protein symbols.
3. Omit every quantitative detail (concentrations, fold-changes, timepoints, thresholds) and every framing word ("does", "is there evidence that", "novel", "identify"). They do not appear in indexed titles or abstracts and narrow the search toward zero.
4. Keep the question's subject. A query broad enough to always return something has stopped serving the question that produced it.

Good: "AcrAB-TolC efflux pump inhibition carbapenem resistance"
Bad: "Does inhibiting efflux pumps restore antibiotic sensitivity?"

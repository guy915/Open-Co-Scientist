# Open Co-Scientist governance

Open Co-Scientist is an open-science community project at
[open-coscientist.com](https://open-coscientist.com). Scientists and developers
can help shape its research methods, evaluations, software and documentation.

## Decisions

Raise questions and early ideas in
[GitHub Discussions](https://github.com/guy915/Open-Co-Scientist/discussions).
Use a feature issue for a concrete proposal and a pull request for a change.
Explain the problem, evidence, alternatives and tradeoffs. Scientific claims
should include sources and a way to check them.

The maintainer seeks community input and records decisions in the relevant
discussion, issue or pull request. Agreement is preferred. When agreement is
not possible, the maintainer makes the final decision and explains why.
Decisions can be revisited when new evidence or constraints emerge.

Changes follow the checks and review rules in
[CONTRIBUTING.md](CONTRIBUTING.md). Passing checks does not guarantee acceptance.
Security reports and conduct reports stay private through their documented
reporting channels.

## Becoming a maintainer

Start with sustained contributions, useful reviews and respectful participation.
Research, evaluation, documentation and community work count alongside code.
Show sound judgment about scientific evidence, user data and project upkeep.

To express interest, open a governance discussion. The current maintainer
reviews the contributor's work and agrees on responsibilities with them.
The maintainer decides whether to invite them and grants access needed for those duties.
There is no fixed contribution count or automatic promotion.

Maintainers may step down. Access and responsibilities can be reduced when
someone is inactive or breaches community standards. Changes to maintainership
and this policy are recorded publicly, with private details kept confidential.
